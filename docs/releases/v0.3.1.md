# Monohero 0.3.1

Adds `monohero queue`, a readable one-time snapshot grouped by project queue.
Shows running jobs, FIFO waiting positions, worktrees, destination chat IDs and
explicit failed/interrupted barriers. `--queue NAME` selects one queue, `--all`
includes history and `--json` emits structured selected jobs.

The existing status wire protocol and `status` JSON remain unchanged. Queue
viewing never claims or changes jobs, starts workflows or refreshes automatically.
The CLI works with existing daemons without restarting active services.

Validation: formatting, clippy with warnings denied, 19 tests, release build and
a read-only snapshot against the existing local daemon.
