# Monohero 0.2.0

- Enqueue an existing Codex chat by exact UUID; native queued messages resume it on grant.
- Separate transport acceptance from the destination's explicit claim.
- Hold the slot until finish; do no protected work after releasing it.
- Notify command-job owners on completion and confirm delivery with acknowledge.
- Independent observer queues and cross-queue same-thread exclusion.
- Private timestamped receipts, failure barriers and no silent retries/expiry.
- New workers use the stable protocol, including on a running 0.1.1 service.
- Updated feedable integration guide and live idle-chat acceptance.

No extra CLI agent, replacement session, private desktop API or permission bypass.
Automatic Claude conversation resumption is not included. Verify queued-message
consumption when installing on a different Codex host/version.
