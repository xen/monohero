# Monohero 0.1.0

Initial Rust CLI release for macOS and Linux.

- Durable FIFO queues with independent project names.
- Detached submission, queue-scoped deduplication, blocking completion wait.
- Private local Unix socket and SQLite journal; no model or timed scheduler polling.
- Failed/interrupted-job barriers, cancellation of queued jobs, explicit resolution.
- Ownership lock inherited by running workflows, preventing overlap after a daemon crash.
- Optional completion executable, private job logs and JSON status.
- Feedable Codex/Claude integration instruction plus opt-in service setup examples.

Install from source with `cargo install --git https://github.com/xen/monohero --tag v0.1.0 --locked`.
The macOS arm64 archive, when attached, contains the standalone executable.

Monohero executes complete authorized command workflows. It does not automatically
resume arbitrary UI chats or enforce exclusion on commands run outside the queue.
