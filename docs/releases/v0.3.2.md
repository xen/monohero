# Monohero 0.3.2

Clarifies same-chat queue authorization in the embedded agent guide. Once the
human approves releasing the current work and using native chat handoff, agents
can enqueue and resume the same chat without asking again merely to select the
queue mode. This creates no nested agent and expands no release permissions.
Projects should update their stale command-only rules alongside the guide.

Other chats, new tasks, first release approval and goal pausing retain their own
requirements. No scheduler, delivery or claim/finish behavior changes.

Validation: formatting, clippy with warnings denied, 19 tests and release build.
